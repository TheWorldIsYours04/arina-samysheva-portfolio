# Арина Самышева — портфолио графического дизайнера

Автономный HTML/CSS/JS-сайт: приветственная страница, галерея, девять проектов и контакты. Adobe Portfolio и Adobe Fonts для его работы не требуются.

## Состояние

Автоматизация уже добавлена в этот репозиторий. **До загрузки пяти архивов с готовыми файлами сайт не опубликован.** Зелёный запуск, в котором этапы Deploy и Verify пропущены, означает только ожидание файлов, а не успешную публикацию.

## Два действия для первого запуска

1. Откройте [Settings → Pages](https://github.com/TheWorldIsYours04/arina-samysheva-portfolio/settings/pages). В разделе **Build and deployment → Source** выберите **GitHub Actions**. Создавать предложенный GitHub workflow не нужно — наш уже находится в `.github/workflows/deploy.yml`.
2. В [окне загрузки файлов](https://github.com/TheWorldIsYours04/arina-samysheva-portfolio/upload/main) загрузите **пять ZIP-файлов** в корень репозитория: `portfolio-part-01.zip`, `portfolio-part-02.zip`, `portfolio-part-03.zip`, `portfolio-part-04.zip`, `portfolio-part-05.zip`. Их нужно взять из выданного в чате комплекта `Arina_Portfolio_Upload_Once.zip`: распакуйте только внешний архив. Внутренние пять ZIP не распаковывайте и не переименовывайте. Дождитесь окончания загрузки и нажмите **Commit changes**, выбрав ветку `main`.

Подтверждённый комплект содержит 268 файлов, включая исходный код, 76 слайдов девяти проектов, обложки и подготовленные версии изображений. Изображения не изменялись при упаковке. Каждый загружаемый архив меньше 25 MiB.

## Что сделает GitHub Actions

Workflow **Publish Arina portfolio** запускается при изменениях `main` и вручную.

- Проверяет SHA-256 каждого из пяти архивов.
- Безопасно извлекает только папки `site/` и `source/`.
- Проверяет 13 HTML-файлов (12 основных страниц и 404), девять проектов, 76 слайдов и локальные ссылки.
- Сохраняет распакованные страницы и изображения в репозитории как обычные файлы. В последующих запусках уже существующий сайт не перезаписывается архивами.
- Собирает canonical URL, robots.txt и sitemap.xml для адреса этого репозитория.
- Публикует только содержимое `site/` через GitHub Pages.
- Проверяет публичные страницы, изображения и настройки контактов. Проверка **не отправляет письма**.

Архивы остаются в репозитории как исходный пакет переноса, но в опубликованный сайт не входят.

Статус смотрите в [Actions](https://github.com/TheWorldIsYours04/arina-samysheva-portfolio/actions). Для завершённой публикации все три этапа должны пройти: **Import, validate and build → Deploy to GitHub Pages → Verify public pages and assets**.

Ожидаемый адрес после успешной публикации: https://theworldisyours04.github.io/arina-samysheva-portfolio/ . До завершения Deploy этот адрес не является подтверждением работающего сайта.

## Локальная проверка после импорта

```bash

python3 source/check_files.py
python3 -m http.server 8000 --directory site
```
